# Elyon Public Proof

Public verification package for the Elyon external-certificate chain.

## Independent verification

```bash
git clone https://github.com/ShantiDraconis/Elyon-Public-Proof
cd Elyon-Public-Proof
lake build
```

The publication manifest records the frozen source commit and the public verification chain. The public repository intentionally excludes private history, local build state, environment files, credentials, and private keys.
