# Problem signatures for the 3..9 layer

This layer prevents arbitrary numerology.

A problem is represented by a ProblemSignature with:
- directionality: inward / outward / bidirectional
- locality: local / global / local-to-global
- obstruction kind: primitive / transfer / algebraicity / complexity / rank / residue / spectral
- closure kind: vanishing / positivity / emptiness
- scalar geometry: discrete / real / complex / mixed
- compression flag
- retraction flag

Digits 3..9 are admissible terminal classes. A named problem may enter a class
only through an exact signature-preservation proof. No digit-to-problem mapping
is asserted yet.

This leaves the next mathematical task well-defined: instantiate signatures
from the actual seven repository endpoints and prove/refute equivalences before
assigning digits.
